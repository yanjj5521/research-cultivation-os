# 问道科研 v3.1.0 使用手册

> 适用版本：问道科研 v3.1.0 自定义洞府正式版  
> 系统原则：本版使用全新的 `wendao-v3-clean.db`，不读取、不合并旧版本数据库。

## 1. 下载哪个版本

### Windows 单机使用

下载 `WendaoResearch-v3.1.0-Windows-x64.exe`。

适合只在一台 Windows 电脑上使用个人端。双击程序即可启动，不需要先安装 Python。

### Windows 便携包

下载 `WendaoResearch-v3.1.0-Portable.zip`，完整解压后再运行。

适合需要保留完整目录、启动团队中心或把软件复制到其他电脑的用户。不要直接在压缩包预览窗口中运行。

### Android

下载 `WendaoResearch-Mobile-v3.1.0-Android.apk`，在系统设置中允许当前文件管理器或浏览器安装未知来源应用后安装。

Android 版为侧载包，不会通过应用商店自动更新。

## 2. Windows 首次启动

1. 把 EXE 或便携包放到有写入权限的普通目录，例如 `D:\WendaoResearch\`。
2. 双击 `WendaoResearchV3.exe`。
3. 等待本地服务启动，浏览器会自动打开个人端。
4. 如果 Windows SmartScreen 提示“Windows 已保护你的电脑”，确认文件来自本仓库后，点击“更多信息”→“仍要运行”。
5. 首次启动会建立全新的正式版数据库。

建议不要把程序放在压缩包、系统目录或受企业权限限制的文件夹中。

## 3. 个人端快速上手

推荐按下面的顺序开始：

1. 进入“设置/个性化”，填写昵称、头像和界面偏好。
2. 在“近期计划”导入未来 3–7 天计划。
3. 把跨天成果目标放入“修炼任务”，把今天可完成的动作放入“每日任务”。
4. 完成每日任务时提交真实交付，例如文字、图片、PDF、PPT、表格、代码或文件夹。
5. 使用论文、笔记、实验、数据集、LAMMPS、MD、ML、COMSOL 等工作区整理科研资料。
6. 每日结束前进行复盘；需要改期时使用“推迟到明天”。

任务只有提交交付后才会完成并结算。计划文本中的 XP、经验或修为数值不会作为奖励依据。

## 4. 自定义主页和界面

### 五档界面密度

在个性化设置中选择适合当前屏幕的密度档位。大显示器可使用更宽松的布局，小屏或分屏时使用更紧凑的档位。

### 主页组件

主页组件支持：

- 显示或隐藏；
- 拖动调整位置；
- 缩放卡片尺寸；
- 一键智能排版；
- 恢复默认布局。

调整完成后先保存。布局混乱或出现空隙时，点击“一键智能排版”；想完全重来时使用“恢复默认布局”。390 px 左右的窄屏会自动切换为单列。

## 5. 修炼与科研模块

### 修炼任务与每日任务

- 修炼任务：跨天能力或成果里程碑，以验收证据为完成标准。
- 每日任务：当天能执行并留下交付的下一步，可以关联某个修炼任务。
- 推迟任务：将任务移至次日，并按系统规则扣除少量灵石。
- 复盘：记录今天的产出、卡点和下一步，不用重复抄写任务。

### 五问雷劫

雷劫用于检查是否真正理解一个主题。按页面五问逐项作答，再根据反馈修正。它不是普通打卡入口，不应靠空白答案或复制原文通关。

### 炼丹炉、成就与彩蛋

- 炼丹炉：使用获得的材料炼制道具，具体配方与结果以页面显示为准。
- 成就图鉴：记录科研、学习、连续行动、资料整理和探索类里程碑。
- 彩蛋柜：展示已经发现的隐藏事件；未解锁项目保留探索空间。

## 6. 团队中心：管理员

便携包中双击 `启动团队中心.cmd`；也可以运行：

```text
WendaoResearchV3.exe --mode team
```

启动后进入管理员登录页。管理员界面与普通成员不同，管理员控制台负责：

- 创建和管理成员；
- 分配或调整角色；
- 重置成员密码；
- 删除成员；
- 发布新版本 ZIP；
- 填写版本号和更新说明；
- 查看发布包校验信息；
- 管理团队中心设置。

首次部署后应立即修改初始管理员密码。管理员凭据、Token 和数据库不得上传到 GitHub、群聊或公共网盘。

发布新版本前，先在另一目录完整解压并测试；上传时只选择正式 ZIP，不要上传开发目录或含个人数据的压缩包。

## 7. 团队中心：普通成员

普通成员登录后进入同行厅，只能使用被授权的成员功能，例如：

- 查看与同步自己的联机状态；
- 浏览团队资料卡；
- 下载管理员发布的版本；
- 发布允许共享的论文线索、数据源、开源工具、复现案例、课程或方法链接。

普通成员看不到管理员的权限管理、密码重置、成员删除和版本发布操作。即使手工访问管理地址，服务端也会进行角色校验。

团队中心只同步系统定义的账号、主页、资产、个性化、资料卡和版本信息；PDF、图片、Word、数据集、交付文件夹等私有科研文件不会默认上传。

## 8. 数据、备份与升级

### v3.1.0 数据规则

本版采用干净新数据库 `wendao-v3-clean.db`：

- 不读取旧版数据库；
- 不自动恢复旧版备份；
- 不把旧数据混入正式版；
- 旧版可以保留在原目录中独立使用。

### 日常备份

定期使用系统内的完整备份功能，并把备份文件复制到另一个磁盘。备份中可能含个人科研记录，应按私密资料管理。

不要把正在运行的 SQLite 数据库放入 OneDrive、NAS 或共享盘，让多台电脑同时打开；这可能造成锁冲突或数据损坏。

### 升级

1. 关闭正在运行的个人端和团队中心。
2. 下载新版本及 `SHA256SUMS.txt`。
3. 校验下载文件。
4. 把新版安装或解压到新目录，不要直接覆盖旧目录。
5. 按新版本说明决定是否导入数据；除非发布说明明确支持，否则不要把旧数据库直接复制进新版。

## 9. SHA-256 校验

在 Windows PowerShell 中进入下载目录后运行：

```powershell
Get-FileHash .\WendaoResearch-v3.1.0-Windows-x64.exe -Algorithm SHA256
Get-FileHash .\WendaoResearch-v3.1.0-Portable.zip -Algorithm SHA256
Get-FileHash .\WendaoResearch-Mobile-v3.1.0-Android.apk -Algorithm SHA256
```

把结果与发行页中的 `SHA256SUMS.txt` 对照。文件名和哈希值都一致再运行。

## 10. 常见问题

### 双击 EXE 没有反应

先等待十几秒，再查看任务栏或浏览器。仍未打开时，把程序移到普通英文路径后重试，并确认安全软件没有隔离程序。

### 浏览器显示无法访问

确认程序窗口仍在运行；不要关闭启动后的后台窗口。端口被其他程序占用时，先结束旧的问道科研进程再启动。

### SmartScreen 阻止运行

当前 Windows 包暂无商业代码签名。只从本仓库发行页下载并完成 SHA-256 校验，然后通过“更多信息”→“仍要运行”。

### 上传新版 ZIP 出现 Internal Server Error

v3.1.0 已修复冻结程序中的版本包上传错误。确认团队中心与个人端均为 v3.1.0，并检查 ZIP 是否完整、文件名是否含异常字符、运行目录是否可写。

### 管理员和成员页面一样

先确认登录账号角色。管理员应进入管理员控制台，普通成员进入同行厅。若角色刚被修改，退出账号并重新登录。

### 布局拖乱了

先点“一键智能排版”；仍不满意时恢复默认布局，再逐个调整组件。

### 忘记成员密码

成员密码不能从数据库中以明文查看。由管理员在控制台为该成员执行密码重置，再把临时密码私下交给本人，并要求首次登录后修改。

## 11. 安全边界

- 不要公开管理员密码、API Token、数据库或个人备份。
- 不要把管理员密码写入共享 ZIP。
- 不要用共享盘让多人直接打开同一个 SQLite 文件。
- 不要把未经校验的第三方“问道科研”安装包当作正式版。
- 团队成员共享资料时优先发布说明与链接，私人原始数据由本人保存。
