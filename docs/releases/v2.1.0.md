# 问道科研 v2.1.0

这是第一个面向普通 Windows 使用者的正式便携发行版。

## 直接使用

- 下载 `ResearchCultivationOS-v2.1.0-Windows-x64.zip`；
- 完整解压后双击 `ResearchOS.exe`；
- 无需安装 Python、pip，也不要求管理员权限；
- 首次启动会在当前 Windows 账户的本地应用数据目录建立个人数据；
- 旧版用户可运行“迁移旧版数据.cmd”导入数据库与科研附件。

## 本次更新

- 保留 v2.0.2 山门、双检索、四个核心入口和轻量工作台；
- 首页只在最底部增加最近保存、工作区、数据位置和版本状态；
- EG、LAMMPS、数据集、ML、MD、COMSOL 默认工作区全部可固定到首页；
- 每个工作区可独立改名、排序、换色、启停、设置目标、编辑 4–6 步流程并组合常用组件；
- ML、MD、LAMMPS、数据集与 COMSOL 使用不同的推荐证据链；
- 程序与个人数据库、个性化、附件分离，换新版不会覆盖个人数据；
- 另提供随整个文件夹移动的 U 盘便携模式；
- GitHub Actions 会在 Windows 环境执行完整回归、生成 one-folder EXE、做打包后自检并发布 SHA-256 校验值。

## 数据边界

数据库、论文、数据集、实验记录、轨迹、附件、Token 和个人配置不会进入 GitHub Release。公开 ZIP 只包含运行程序与使用说明。
