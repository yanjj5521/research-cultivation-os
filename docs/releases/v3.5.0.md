# 问道科研 v3.5.0

## 科研主线优先

- 首页和导航改为：文献阅读与汇报、课题推进、知识库优先；每日任务成为可选激励。
- 增加“随手推进”：无需导入计划，也能把一个判断、事实或下一步归档成可编辑知识卡。
- 每日任务的文字交付同步生成可编辑归档；原文件仍保存在交付包中。

## 图优先文献汇报

- 从知识库 PDF 抽取候选图片，并为矢量图渲染 Figure 页面。
- 选择 1–3 张关键图后，生成 8 页汇报骨架、3 分钟口述稿和图片汇报 PPT。
- 汇报保存为可编辑知识卡，后续可修订证据、结论和课题连接。

## 同行会与桌宠

- 同行会在同一 EXE 内按管理员/成员身份显示不同界面。
- 管理员可在同行会页启动或停止本机中心，不再需要单独的 CMD 启动器。
- 灵知支持滚轮缩放、右键菜单、拖拽、轻量呼吸浮动与大小记忆。
