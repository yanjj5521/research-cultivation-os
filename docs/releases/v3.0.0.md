# 科研系统 1.0

技术版本：`v3.0.0`

这是“问道科研”之后的首个“科研系统”正式版本。技术版本升至 3.0.0，是为了保证旧版 v2.3.1 能被安全识别为较早版本；产品名称从这一版起统一为“科研系统 1.0”。

## 本版重点

- 产品定位升级为陪伴完整科研生涯的成长系统：课题问题、近期计划、每日交付、证据闸门、复盘、生涯节点和下一阶段连续衔接。
- 课题可以关联多个工作区，实验、计算、数据、写作等空间共同服务同一个科学问题。
- 近期计划新增可执行度检查、快速加任务、工作区/课题关联和可直接导入的 AI 文本格式。
- AI 协作台新增九种用途和范围筛选，核对后的结果可以回存知识库、课题推进或两者。
- 本地个性化扩展为色彩、场景、动效强度、几何语言、信息密度、字号和主页几何效果；v8 个性化包继续兼容 v1–v7。
- 内置古诗词池显著扩充，保持按日期离线轮换。
- 洞府重新设计为极简几何山水，保留日夜、落日、飞鸟、轨道和低干扰动态。
- 成就图鉴扩展为 23 枚带进度的成就，并集中展示可发现彩蛋。
- 法器扩展为 12 件，每件明确标注作用；归一炉会真实增加任务材料奖励，其余法器会改变专注、校核、AI 回存、证据提示、复盘提醒、检索或秘境体验。
- 秘境扩展为灵光问答、因果迷宫、反证之境、万象秘境和突破雷劫。
- 在主页、洞府、计划、AI 协作、课题、交付、复盘和生涯节点中布置可追踪彩蛋。
- 网页、Windows EXE 和 Android APP 统一使用两色、无文字的极简几何图标。

## 数据与升级

- 旧数据库会原位新增课题—工作区关联表、任务关联字段和个性化设置。
- 开放知识库导出升级为 v5，新增 `project_workspaces.json`，课题的多工作区关系不再只存在于 SQLite 中。
- 自定义站点名称不会被覆盖；仅旧默认名“问道科研”自动迁移为“科研系统”。
- 旧资料、附件、交付、课题、工作区、法器、灵石和联网配置均保留。
- 本地资料仍默认不上传；ResearchHub 只同步账号、公开主页、轻量资产、个性化和版本信息。
- 内部数据目录继续沿用 `ResearchCultivationOS`，用于保证旧数据自动识别，这不影响产品显示名称。

## 发行物

- `ResearchOS-v3.0.0-Windows-x64.exe`：个人科研端。
- `ResearchHub-v3.0.0-Windows-x64.exe`：十人以内轻量联机中心。
- `ResearchCultivationOS-v3.0.0-Windows-x64.zip`：完整 Windows 联机与迁移套件。
- `ResearchOS-Mobile-v3.0.0-Android.apk`：Android 移动入口。
- `SHA256SUMS.txt`：发行文件完整性校验。

Windows EXE 暂无商业代码签名，首次运行可能显示 SmartScreen；Android APK 为侧载安装包。
