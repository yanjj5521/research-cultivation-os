# 问道科研 v3.6.0

## 学习使用率优化

- 默认路径压缩为：读文献、讲关键图、写英文、做图、存知识；计划、任务与游戏化不再抢占侧栏注意力。
- 保留所有低频模块，但默认隐藏，仍可在“设置与备份 → 调整导航”中重新开启。
- 闭关静修的自定义壁纸升级为本地壁纸库；可保留并切换多张图片，绝不上传同行会。

## 同行会：讨论、短沟通与互助

- 新增论坛：帖子和回复适合记录问题、方法与可靠线索；作者和管理员可以删除自己的公开内容。
- 新增轻量聊天：20 秒刷新一次，不使用强提醒或无限历史刷屏；需要沉淀的内容应回到论坛或个人知识库。
- 新增同行坊市：支持修为、灵石、灵木、玄铁、星砂的虚拟红包与指定成员间的交换提议。
- 红包即时转入收款方；交换只有对方接受、且双方余额都足够时才会同时成交，不会发生部分转账。

## 数据与安全边界

- 不支持真实货币、支付、提现或任何外部交易。
- 同行会仅保存账号、公开主页、公开交流、虚拟资产与版本信息；个人 PDF、笔记、实验原始数据与知识库附件仍只存个人电脑。
- 新增社交表、聊天表和交易表均由同行会独立数据库管理，不改动个人主数据库或旧资料。
