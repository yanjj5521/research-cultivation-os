# 问道科研 v3.1.0 · 自定义同行版

技术版本：`v3.1.0`

## 本版重点

- 同行会明确区分管理员与普通成员。管理员拥有成员、邀请码、版本上传、备份与审计控制台；普通成员只管理自己的同步、资料卡和版本下载。后端继续强制角色鉴权。
- 修复冻结 Windows 程序中上传新版 ZIP 可能出现 `Internal Server Error` 的路径问题。版本包保存到用户数据区，自动创建目录，并在入库前校验 ZIP 完整性与 EXE 结构。
- 增加专注、宽松、舒适、紧凑、极简高密五档界面密度。
- 主页进入可编辑模式后可拖动模块、调整宽度并保存；“一键智能排版”会按当前屏幕宽度恢复协调布局。
- 五问雷劫改为“事实—机制—边界—反证—迁移”五段式突破界面。
- 炼丹炉扩展至 9 种丹方，并增加丹方谱与炼制彩蛋。
- 成就图鉴扩展至 45 项，新增 22 项可追踪成就。
- 彩蛋柜扩展至 30 枚，增加进度、发现日期与隐藏线索。

## 数据边界

本版继续使用 `wendao-v3-clean.db`，不读取或迁移任何旧版 SQLite 数据库。Windows 普通模式、便携模式与 Android 仍保持独立数据身份。

## 发布门禁

- 源码契约、干净数据库、自检、个人端、同行会与联机事务测试。
- 管理员/成员页面与后端权限回归测试。
- 冻结程序用户数据目录中的版本 ZIP 上传与下载回归测试。
- Windows 单 EXE、四文件便携包、桌面与窄屏渲染。
- Android 测试、Lint、签名与独立包名。
