# 问道科研 v2.3.0

## 直接使用

- Windows 个人科研端：下载并双击 `ResearchOS-v2.3.0-Windows-x64.exe`；
- Windows 联机中心：下载并双击 `ResearchHub-v2.3.0-Windows-x64.exe`；
- Android：下载并安装 `ResearchOS-Mobile-v2.3.0-Android.apk`；
- 需要 U 盘模式、旧版迁移或同机启动两端时，下载完整 Windows ZIP。

Windows EXE 不要求预装 Python、pip 或管理员权限。Android APK 用于连接已经运行的 ResearchHub：局域网可使用私有 HTTP 地址，公网中心必须使用 HTTPS。

## 从知识库走向科研生涯系统

新增“生涯罗盘”：

- 记录当前科研阶段、本阶段目标、主动边界、完成信号和复看日期；
- 串联关键决策、突破、失败转化、能力形成、成果、合作和方向转折；
- 从活跃课题证据闸门、近期计划和已有状态中给出唯一下一步；
- 不用数量自动评判科研质量，也不替用户锁定长期主线；
- 生涯节点进入 JSON、开放知识库 ZIP 和完整备份。

旧默认身份“准研一修士”会迁移为“修士”；用户自行设置的姓名不会被覆盖。

## 法器购买与动态山门

- 开宗礼包 12 灵石现在可刚好购入清心玉简；
- 法器卡直接显示价格、缺口、拥有与佩戴状态；
- 交易使用原子写入，并覆盖刚好足够、余额不足和重复购买三类回归；
- 首页按本地时间切换晨曦、日间、落日和月夜；
- 飞鸟、余晖、微光、山雾与轻量视差遵守系统“减少动态效果”设置。

## 联机与 Android

- “保存并联机”一次完成地址校验、首次轻量状态合并和自动同步开启；
- ResearchHub 启动窗口显示 Android 地址和一键配对链接；
- Hub 页面底部可直接唤起 APK 并带入当前中心地址；
- Android WebView 禁用 JavaScript 与原生桥，只保留同源导航；
- 个人论文、实验数据库和附件不进入 Hub 或 APK。

## 构建与升级

GitHub Actions 会：

1. 运行个人端、课题、生涯、法器、开放导出和旧库迁移测试；
2. 启动真实 ResearchHub 进程验证首次联机、自动同步与法器交易；
3. 在 Windows runner 构建并自检两个单文件 EXE；
4. 在 Android 工具链运行单元测试、Lint、APK 构建与签名检查；
5. 汇总双 EXE、APK、完整 ZIP 和统一 `SHA256SUMS.txt` 后创建不可变 Release。

首次启动会原位新增生涯节点表并把数据库版本更新为 `2.3.0`。现有计划、课题、任务、交付、论文、附件、工作区、个性化、法器、成长状态与联机配置均保留。
