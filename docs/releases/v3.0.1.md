# 问道科研 3.0 模块化清洁版

技术版本：`v3.0.1`

## 本版原则

- 产品表面严格回到原始 `v3.0.0`。
- 仅改变底层模块、数据库创建方式、发行启动与动效实现。
- 不提供旧数据库迁移。

## 验证合同

- 除 `base.html` 的新版动效挂载点外，原始 3.0 模板与主样式逐文件 SHA-256 固定。
- 原始 3.0 全部路由方法、路径和名称固定。
- 清洁 Schema 一次创建 43 张最终表，不执行 `ALTER TABLE`。
- 新数据库播种 6 个工作区、8 条路线与 6 个起步任务。
- 无控制台启动不依赖 `stdout`、`stderr` 或 Uvicorn 默认日志格式化器。
- 同一 EXE 提供个人端和团队中心。
- Android 使用独立应用标识。
