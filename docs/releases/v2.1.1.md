# 问道科研 v2.1.1

这是一次面向实际使用的修复版：近期计划可以可靠导入、切换，正式版也可以直接下载单个 EXE。

## 最简单的使用方式

1. 下载 `ResearchOS-v2.1.1-Windows-x64.exe`；
2. 双击 EXE，等待浏览器自动打开；
3. 使用时保持黑色运行窗口打开，关闭窗口即可停止系统。

不需要解压，不需要安装 Python、pip，也不要求管理员权限。个人数据库、附件和个性化继续保存在 `%LOCALAPPDATA%\ResearchCultivationOS`，替换 EXE 不会覆盖它们。

## 近期计划修复

- 支持粘贴标准 Markdown，也支持从 ChatGPT 页面选择复制得到的纯文本；
- 可识别 `•` 项目符号、`第一天`、`第1天`、`Day 1`、中文分钟和不带 `#` 的标题；
- 导入成功后自动启用新计划，并直接进入 Day 1；
- 每份归档计划旁都有明确的“启用”按钮；
- 归档计划预览不再显示为“正在使用”；
- 不存在的计划编号不会归档或清空当前计划；
- 新旧计划切换始终保证只有一份计划处于使用中。

## 首页微调

首页原有山门、每日诗句、头像、双检索、四个核心入口、工作台和底部状态保持原结构，只对搜索说明、头像信息、入口说明、工作台与底部状态等过小文字做了小幅放大。

## 发行与验收

- Release 直接提供单个 Windows x64 EXE；
- 同时保留便携 ZIP，用于 U 盘模式、旧版迁移和桌面快捷方式；
- Windows 构建完成后会运行打包程序本身；
- 打包后自检会实际提交一份纯文本近期计划，验证自动启用、进入每日任务、归档计划切换和无效切换保护；
- `SHA256SUMS.txt` 同时覆盖 EXE 与便携 ZIP。

数据库、论文、数据集、实验记录、附件、Token、管理员凭据和个人配置均不进入公开发行物。
