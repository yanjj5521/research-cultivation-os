# 问道科研 v2.3.1

## 直接使用

- Windows 个人科研端：下载并双击 `ResearchOS-v2.3.1-Windows-x64.exe`；
- Windows 联机中心：下载并双击 `ResearchHub-v2.3.1-Windows-x64.exe`；
- Android：下载并安装 `ResearchOS-Mobile-v2.3.1-Android.apk`；
- 需要 U 盘模式、旧版迁移或同机启动两端时，下载完整 Windows ZIP。

Windows EXE 不要求预装 Python、pip 或管理员权限。Android APK 连接已经运行的 ResearchHub；局域网可使用私有 HTTP 地址，公网中心必须使用 HTTPS。

## 自己编排导航

- 在“设置与备份 → 导航顺序与显示”中拖动分组或条目；
- 分组和组内条目都支持排序，触屏或窄屏可使用上下箭头；
- 每个固定页面入口可以独立显示或隐藏；
- 当前启用的动态工作区入口可以作为一个整体显示或隐藏；
- “恢复默认”会恢复默认分组、条目顺序和全部显示状态；
- 即使隐藏“设置与备份”，侧栏底部仍保留“调整导航”安全入口。

隐藏只影响侧栏，不会删除页面、课题、论文、任务、交付或附件。稳定键和 URL 始终不变。

## 跨版本与联机

- 新增 `nav_layout` 稳定布局设置；
- 标准化器会拒绝未知与重复项，并在未来新增入口时自动补齐；
- 个性化包升级为 v7，包含导航名称、分组顺序、条目顺序和显示状态；
- 继续兼容 v1–v6 个性化包；旧包没有布局时使用默认布局；
- ResearchHub 会同步经过校验的 v7 导航布局，论文、实验数据、个人笔记和附件仍只保存在本机。

## 保留 v2.3.0 的完整能力

科研生涯罗盘、旧默认身份迁移、可购买法器、昼夜山门、落日飞鸟、保存并联机、双 Windows EXE、Android APK、旧库原位迁移与本地数据隔离全部保留。
