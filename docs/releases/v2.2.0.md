# 问道科研 v2.2.0

## 普通用户下载

- 个人使用：下载并双击 `ResearchOS-v2.2.0-Windows-x64.exe`；
- 小团队联机中心管理员：另行下载并双击 `ResearchHub-v2.2.0-Windows-x64.exe`；
- 需要 U 盘模式、数据迁移或同机启动两端时，下载完整 ZIP；
- 两个 EXE 均不要求预装 Python、pip 或管理员权限。

## 新增：课题推进

- 输入科学问题、价值、目标成果、成功标准、当前基础、现实约束、检索词、工作区与可选目标日期；
- 自动建立 5 个可修改的证据闸门；
- 只有写入证据或决策理由后，闸门才能标记通过；
- 按需使用 Crossref 查找相关论文并保存为基线、方法、反例或相邻启发；
- 保存推进、证据、卡点、失败、关键决策与唯一下一行动；
- 从当前闸门生成可直接导入的三日计划；
- 可复制严格审查提示词给任意大模型，要求它优先指出反证、风险和下一轮最小实验。

## 完整双 EXE

- `ResearchOS.exe` 保存个人计划、课题、论文、实验、工作区和附件；
- `ResearchHub.exe` 提供账号、邀请码、公开主页和轻量状态同步；
- 个人数据与中心数据使用不同目录，升级程序不会覆盖；
- 只做个人使用的人无需下载或运行联机中心。

## 升级与兼容

首次启动会在原数据库中新增课题推进表，并把数据库版本更新为 `2.2.0`。现有计划、任务、交付、论文、附件、工作区、个性化、成长状态和联机关闭状态均保留。

发布资产包括两个单文件 EXE、完整 ZIP 和 `SHA256SUMS.txt`。Windows 构建会分别执行个人节点与联机中心的打包后自检。
