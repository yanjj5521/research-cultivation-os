问道科研 · Windows 公开发行版
================================

一、最简单启动

1. 从 GitHub Release 下载单个 ResearchOS-v版本-Windows-x64.exe。
2. 双击 EXE；浏览器会自动打开问道科研。
3. 黑色运行窗口需保持打开，关闭它即可停止系统。

不需要安装 Python，不需要 pip，不需要管理员权限。

若你下载的是便携 ZIP，请先完整解压，再双击其中的 ResearchOS.exe；
不要在压缩包预览窗口中运行。

二、个人数据在哪里

普通模式：
  %LOCALAPPDATA%\ResearchCultivationOS

程序、数据库、个性化配置和附件彼此分开。以后换新版时，只需完整解压
新版并运行；它会继续读取同一份个人数据。

双击“打开数据目录.cmd”可直接打开当前数据目录。

三、从 v2.0 源码文件夹迁移

双击“迁移旧版数据.cmd”，粘贴旧版根目录路径。旧目录中应包含
instance 和 storage。迁移使用 SQLite 一致性备份，不直接复制正在写入的
数据库；目标已有数据时不会静默覆盖。

四、U 盘/随身便携模式

双击“便携模式启动.cmd”。数据将写入本文件夹的 user_data。
移动时必须连同整个文件夹一起复制，并先关闭程序。

五、更新原则

- 正式版优先提供一个可直接双击的 EXE，同时保留便携 ZIP；
- 下载新版 EXE 后直接运行，旧版程序文件可自行保留或删除；
- 普通模式个人数据独立保存，不随程序更新被替换；
- 仍应定期在网页“设置与备份”中下载完整备份。
