# 问道科研 · 正式版 v1.1

一个面向 10 人以内小团队的“本地科研空间 + 轻量联机同行会”。

它不把所有人的论文、数据和图片塞进同一个服务器，而是采用更稳妥的混合结构：

- 每个人在自己的电脑上保存科研资料、笔记、数据集和任务交付；
- 一个轻量联机中心同步账号、公开主页、灵石与资材、法器/建筑、个性化方案和软件版本；
- 需要共享的论文或数据，只发布资料卡、摘要、标签与链接；
- 管理员发布新版 ZIP，成员下载后用安全更新器安装到新目录。

## 启动

个人科研节点：双击 `启动科研系统.cmd`，默认地址 `http://127.0.0.1:5000`。

联机中心：双击 `启动联机中心.cmd`，默认地址 `http://127.0.0.1:5050`。
