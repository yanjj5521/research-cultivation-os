# 问道科研 · Research Cultivation OS v2.0.1

一个本地优先、交付驱动的个人科研操作系统。轻量同行会仍可兼容小团队，但 v2.0 默认关闭联机，只预留未来规模化后端接口。

它不是另一个待整理的资料仓库，也不是靠连续签到制造焦虑的打卡器。它把检索、计划、交付、复盘和长期科研资产连接为一条可重复流程：

```text
打开首页
→ 搜自己的知识或联网找论文
→ 进入今日修炼
→ 留下真实交付
→ 次日从记忆中提取
→ 论文、笔记、数据和能力证据长期积累
```

修仙外观可以自定义，经验规则和科研数据结构保持稳定；漏一天不会清空长期成长，奖励只来自可追溯的真实行动。

## v2.0.1：轻量山门首页

首页恢复为清晰的山门入口，不再重复各功能页面中的任务、论文、奖励和数据卡片：

- **山门视觉**：保留每日诗句、头像、境界和轻量山水动效；
- **双检索**：同一输入框可搜索本地知识库，也可按需联网搜索 OpenAlex；首页加载不会自动联网；
- **四个直达入口**：修炼、温故、闭关和藏经阁；
- **渐进呈现**：计划、论文卡、保存、备份、工作区和成长数据回到侧栏及各自页面，避免首页成为控制台。

桌面侧边栏仍按使用频率稳定分为：今日修炼、知识与交付、我的工作区、秘境与成长、协作与系统。动态工作区、39 阶境界、金丹后雷劫、每日计划、论文资料、完整备份和联机扩展接口全部保留。

## 修炼任务与每日任务

两类任务使用不同数据和完成标准：

- **修炼任务**：跨天的能力或成果里程碑，例如“能够独立判读 CV 曲线”“形成可复现 LJ 案例”；必须提交验收证据才可完成。
- **每日任务**：某一天可执行的下一行动，例如“判读一张曲线”“补齐 README”；通过当天真实交付完成。
- 每日任务可以关联并推进修炼任务，但不会自动替用户宣布里程碑完成。
- 一份 AI 文案可同时包含“修炼任务”和 `Day N` 计划，导入后仍分别保存。

经验值不再由计划文本或表单决定。导入文案里的 `XP / 经验 / 修为` 会被忽略；每日任务按时长档位统一计算，修炼任务按小成 / 进阶 / 突破统一计算。

## 每个人自己的工作区

EG 实验、LAMMPS 和数据集现在只是三种默认模板，不再假定所有用户拥有相同方向：

- 可新建、改名、排序、停用工作区；
- 可选择通用知识专题、实验台账、模拟案例或数据集类型；
- 导航根据本人的工作区动态生成；
- 工作区定义进入 v5 个性化包；记录和附件仍进入完整备份与知识库导出。

### 一键导出知识库

知识库导出不是数据库黑盒，而是一个可直接阅读的 ZIP：

- 每条记录一份 CommonMark 友好的 Markdown；
- 完整结构化 `knowledge.json`；
- 原始附件；
- 工作区、实验、模拟和复盘关键文本索引；
- 不包含游戏资产、API 密钥、联机 Token 或程序。

需要完整恢复时仍使用“完整备份”；需要带着全部程序迁移时使用“整套便携迁移包”。

## 核心科研闭环

```text
AI 生成 3–7 天近期计划
→ 粘贴导入
→ 完成任务并上传真实交付
→ 同时留下 3–8 条复盘关键文本
→ 下次打开主页弹出延迟复盘
→ 开放题回答、证据核对、本人确认掌握度
→ 特殊任务获得分级灵草
→ 在独立秘境中做综合迁移；到大境界门槛时才开启雷劫
```

### 近期计划

- 不再建立不可变的长期主线；
- 网站根据当前目标、未完成事项、最近交付和状态生成提示词；
- 将提示词复制给任意大模型，粘贴模型返回的 Markdown 即可导入；
- 提示词明确区分跨天里程碑与当天行动，且禁止模型输出经验值；
- 新计划可以随时替换旧计划，不产生“欠了几十天”的补课负担。

### 交付驱动复盘

- 每次任务可以上传文字、文件或完整文件夹；
- “复盘关键文本”会作为 `复盘关键文本.txt` 放入该次交付目录；
- 自动复盘只读取这段关键文本，不扫描全部论文、实验数据或私人资料；
- 参考证据在回答后才显示；
- 开放题按证据和评分点给出部分得分、反馈与置信度，最终掌握度由本人确认。

### 秘境与突破

- 特殊任务按 1–5 级产生凡品、灵品、玄品、地品和天品灵草；
- 灵草可炼制清心丹、凝元丹与渡劫丹；
- “万象秘境”是独立综合试炼，不再混在复盘页；
- 五问雷劫只在金丹以上、修为达到下一大境界门槛时出现，均分达到 70 分才解锁突破；
- 秘境与雷劫只从用户自己的复盘材料中出题；
- 游戏奖励不能替代交付，所有资源都应能追溯到真实行动。

### 可迁移个性化

- 网站名、39 阶境界名、全部导航名、诗句池、工作区定义、主题、主页信息和复盘开关可导出为 JSON；
- 个性化包不包含论文、数据、附件、API 密钥或联机 Token；
- v2.0 能导入 v1–v5 个性化包；v5 使用稳定境界键并携带压缩头像、每日诗句池与工作区定义；
- 升级时保留本地 SQLite 数据库和 `storage/` 中的科研文件。

## 快速启动

### Windows

双击：

```text
启动科研系统.cmd
```

默认打开 `http://127.0.0.1:5000`。

### Linux / macOS

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python run_local.py
```

### 运行自检

```bash
python self_test.py
python hub_self_test.py
```

## AI 模式

系统始终可以在离线规则模式运行。外部模型不可用时，复盘和特殊任务会安全回退，不会阻止正常交付。

### 本地 Ollama

在“设置与备份”中选择“本地 Ollama 模型”，填写接口和模型名，例如：

```text
http://127.0.0.1:11434/api/generate
```

### OpenAI / Responses 兼容接口

1. 在系统环境变量中设置密钥；
2. 在网页设置中选择“外部 OpenAI / 兼容接口”；
3. 填写 Responses API 地址和你账号可用的模型名。

Windows CMD：

```bat
set OPENAI_API_KEY=你的密钥
启动科研系统.cmd
```

Linux / macOS：

```bash
export OPENAI_API_KEY="你的密钥"
python run_local.py
```

密钥只从 `OPENAI_API_KEY` 或 `RESEARCH_OS_AI_KEY` 环境变量读取。不要把密钥写进源码、JSON 个性化包或 GitHub。

## 数据保存位置

| 数据 | 默认位置 | 是否同步到轻量中心 |
|---|---|---:|
| 个人数据库 | `instance/research_os.db` | 否 |
| 论文、图片、数据集 | `storage/uploads/` | 否 |
| 每日与特殊任务交付 | `storage/deliveries/` | 否 |
| 个人头像 | `storage/profile/` | 否 |
| 模拟案例 | `storage/simulations/` | 否 |
| 身份、主题、境界名、导航名、工作区定义 | SQLite / 个性化包 | 可选 |
| 灵石、法器、建筑等轻量状态 | SQLite | 可选 |

SQLite 使用 WAL 模式；自动备份通过 SQLite Backup API 创建一致性快照。仍建议定期把完整备份复制到另一块磁盘或可信云盘。

## 联机扩展

默认模式为“关闭”：本机不会新增同步队列，也不会上传或拉取状态。`services/sync_backend.py` 提供统一适配器边界，`docs/scalable-sync-api.openapi.yaml` 固定未来云端的版本化契约；规模化服务器、统一登录与多租户数据库尚未实现。

已有小团队仍可显式选择“轻量同行会”兼容模式：

双击 `启动联机中心.cmd`，默认地址为 `http://127.0.0.1:5050`。

中心负责：

- 账号与公开主页；
- 轻量游戏资产；
- 个性化配置；
- 资料链接卡；
- 软件版本发布。

中心不承担公共网盘职责。大型科研文件继续由每位成员本地保存，或使用成熟的共享盘、对象存储和机构平台。

## 项目结构

```text

db.py                     本地数据库与就地迁移
features/daily.py         近期任务与交付
features/review.py        昨日复盘、独立秘境与突破雷劫
features/alchemy.py       特殊任务、灵草与炼丹
features/workspaces.py    个人工作区定义与入口
services/ai_provider.py   Ollama / Responses 结构化调用
services/review_engine.py 出题、评分与离线回退
services/prompt_builder.py 动态计划提示词
services/progression.py   固定经验规则、39阶境界与突破门槛
services/sync_backend.py  可替换联机后端接口
services/profile_media.py 头像验证、压缩与迁移
hub_app.py                轻量联机中心
safe_update.py            安全升级与旧数据迁移
```
