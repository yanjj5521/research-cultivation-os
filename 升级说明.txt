问道科研 v2.2.0 → v2.3.0

一、普通 Windows 用户
1. 下载 ResearchOS-v2.3.0-Windows-x64.exe。
2. 双击即可使用，不需要解压、Python、pip 或管理员权限。
3. 浏览器自动打开后，黑色运行窗口需保持打开。
4. 旧数据仍从 %LOCALAPPDATA%\ResearchCultivationOS 读取，无需复制。
5. 升级前建议先在“设置与备份”中生成一次完整备份。

二、需要联机的小团队
1. 每位成员仍运行自己的 ResearchOS.exe。
2. 负责中心的人另下 ResearchHub-v2.3.0-Windows-x64.exe。
3. 中心默认端口为 5050；首次运行会显示局域网地址、Android 配对链接和一次性管理员凭据。
4. 个人端“联机扩展”选择 ResearchHub 后，可点击“保存并联机”，一次完成首次合并和自动同步。
5. 中心数据位于 %LOCALAPPDATA%\ResearchCultivationOSHub，不与个人数据混用。

三、Android
1. 下载 ResearchOS-Mobile-v2.3.0-Android.apk。
2. Android 可能要求允许“安装未知应用”，只应从本项目正式 GitHub Release 安装。
3. 手机与中心电脑在同一局域网时，填写窗口显示的 192.168.x.x:5050。
4. 公网地址必须使用 HTTPS，不能直接暴露 5050。
5. APK 只进入 ResearchHub；论文、实验数据库和附件仍保存在个人电脑。

四、科研生涯罗盘
- 当前阶段不再绑定“准研一”，旧默认身份自动改为“修士”；
- 记录阶段目标、主动边界、完成信号与复看日期；
- 保存关键决策、失败转化、技能、成果、合作和方向转折；
- 系统从课题闸门和近期计划中提示唯一下一步；
- 生涯节点进入开放导出与完整备份。

五、法器与山门
- 开宗礼包 12 灵石可刚好购买清心玉简；
- 法器卡显示价格、缺口和拥有状态，重复购买不会重复扣款；
- 首页按本地时段显示晨曦、日间、落日或月夜，并加入飞鸟、余晖和微光；
- 系统开启“减少动态效果”时，持续装饰动画自动关闭。

六、旧数据升级
首次启动会新增 career_moments 表并把数据库版本更新为 2.3.0。旧论文、课题、笔记、交付、数据集、实验、模拟、计划、修为、灵石、法器、洞府、头像、39 阶境界、雷劫、自定义导航、工作区个性化与联机配置不会删除或重置。只有仍等于旧默认值“准研一修士”的姓名会改为“修士”，自定义姓名保持不变。

七、程序与开发版
- ResearchOS.exe：个人端。
- ResearchHub.exe：轻量中心。
- Android APK：手机联机入口。
- 完整 ZIP：个人/中心便携模式、同机双启动、迁移和数据目录入口。
- 私有 development/next：开发源码；正式 EXE 仍可供开发者日常使用。

八、版本保存
- 公开 main 只指向最新稳定版；
- 私有 development/next 用于继续开发；
- 本版同时保存为两个仓库中的 release/v2.3.0；
- GitHub Release 标签为 v2.3.0，并提供两个 EXE、Android APK、完整 ZIP 和统一 SHA-256。
