问道科研 v2.1.1 → v2.2.0

一、普通 Windows 用户
1. 只做个人科研：下载 ResearchOS-v2.2.0-Windows-x64.exe。
2. 双击即可使用，不需要解压、Python、pip 或管理员权限。
3. 浏览器自动打开后，黑色运行窗口需保持打开。
4. 旧数据仍从 %LOCALAPPDATA%\ResearchCultivationOS 读取，无需复制。
5. 升级前建议先在“设置与备份”中生成一次完整备份。

二、需要联机的小团队
1. 每位成员仍只运行自己的 ResearchOS.exe。
2. 负责中心的人另下 ResearchHub-v2.2.0-Windows-x64.exe，并在一台会保持开机的电脑上运行。
3. 中心默认端口为 5050；首次运行会显示局域网地址和一次性管理员凭据文件位置。
4. 中心数据位于 %LOCALAPPDATA%\ResearchCultivationOSHub，不与个人数据混用。
5. 不需要团队联机时，不必下载或运行 ResearchHub。

三、新增课题推进
- 输入课题名称、科学问题、价值、目标成果、成功标准、当前基础、现实约束与检索词；
- 系统生成 5 个可修改的证据闸门；
- 空白闸门不能直接通过，必须留下证据或决策理由；
- 点击后使用 Crossref 联网查找论文，首页打开时不会自动联网；
- 相关先例可标记为直接基线、可借方法、反例/冲突或相邻启发；
- 推进记录保存真实发现、证据、卡点、把握度和唯一下一行动；
- 当前闸门可生成三日计划，并直接进入已有“近期计划”导入链。

四、程序与数据
- ResearchOS.exe：个人节点，数据目录为 %LOCALAPPDATA%\ResearchCultivationOS。
- ResearchHub.exe：轻量中心，数据目录为 %LOCALAPPDATA%\ResearchCultivationOSHub。
- 完整 ZIP：另含个人便携模式、中心便携模式、同机双启动、迁移和数据目录入口。
- 源码仓库和 Developer_Start_All.cmd 只用于开发，不是普通用户安装方式。

五、旧数据升级
首次启动会新增课题推进所需数据表并把数据库版本更新为 2.2.0。旧论文、笔记、闪念、交付、数据集、实验、模拟、计划、修为、灵石、洞府、头像、39 阶境界、雷劫、自定义导航、工作区个性化与联机关闭状态不会删除或重置。

六、版本保存
- 公开 main 只指向最新稳定版；
- 私有 development/next 用于继续开发；
- 本版同时保存为两个仓库中的 release/v2.2.0；
- GitHub Release 标签为 v2.2.0，并提供两个 EXE、完整 ZIP 和 SHA-256。
