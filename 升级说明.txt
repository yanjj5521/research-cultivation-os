问道科研 v2.0.1 → v2.0.2

一、升级前
1. 在旧版“设置与备份”中点击“完整备份”，把 ZIP 复制到安全位置。
2. 下载并完整解压 v2.0.2，不要直接覆盖正在使用的旧目录。
3. 关闭旧版网页和黑色命令窗口。
4. 双击 v2.0.2 的 Restore_Data.cmd，选择旧版完整备份 ZIP。
5. 双击 启动科研系统.cmd。

首次启动会把数据库版本更新为 2.0.2。旧论文、笔记、闪念、交付、数据集、实验、模拟、计划、修为、灵石、洞府、头像、39 阶境界、雷劫记录、工作区和自定义导航不会删除。

二、v2.0.2 首页与默认工作区
- 保留 v2.0.1 的山门、每日诗句、头像、境界、四个直达入口和双检索；
- 首页底部增加一条低密度工作台坞，只放 ML、MD、COMSOL、全部工作区和联机保护状态；
- 工作台坞不恢复任务仪表盘、论文轮播、每日一问、闪念、奖励或备份卡片；
- 桌面低高度下会自动压缩山门和入口，手机窄屏允许自然滚动；
- 默认工作区从 EG、LAMMPS、数据集扩展为 EG、LAMMPS、数据集、ML、MD、COMSOL；
- ML 收纳数据边界、特征、训练、验证与模型卡；MD 使用结构化模拟台账；COMSOL 保留假设、边界条件、网格、求解器与实验校核；
- 新默认工作区使用稳定内部键，升级只补缺项，不覆盖已有工作区的个性化名称和启停状态。

三、管理员怎么设置
- 第一次启动“轻量联机中心”时，如果数据库里没有管理员，系统只创建一个用户名为 admin 的管理员；
- 随机初始密码与 API Token 只写在中心主机的 instance/HUB_ADMIN_CREDENTIALS.txt；
- 管理员首次登录后应立即修改密码；修改成功后系统自动销毁这份一次性凭据文件；
- API Token 仍可在“我的联机主页”查看或重新生成，重新生成后旧 Token 立即失效；
- 普通成员只能凭管理员生成的邀请码注册，角色固定为 member，网页没有自助提权入口；
- 管理员可管理邀请码、成员启停、版本包、中心备份和同步审计，但不能读取成员电脑上的论文、实验、数据集或附件。

四、联机不稳定时的保护
- 联机默认关闭；关闭时不新增队列、不上传、不拉取；
- 本地保存先成功，联机失败不会回滚论文、交付或设置；
- 自动同步单次超时 1.5 秒，只重试临时错误，使用指数退避与抖动，并遵守中心 Retry-After；
- 连续 3 次失败后自动熔断至少 5 分钟，避免网络抖动拖慢本机；
- 每个事件有唯一 UUID，重复提交由中心按幂等事件处理；
- 单个事件尝试 6 次后暂停，认证或参数错误直接转人工检查；
- 联机页可手动检测地址与 Token、查看延迟、恢复暂停事件；
- 公网地址必须使用 HTTPS；HTTP 只允许本机或私有局域网；
- 中心健康检查会真实访问数据库，异常时返回 503 与 Retry-After；
- 中心数据库使用 SQLite WAL、忙等待和 Backup API，不要放入共享盘让多人直接打开。

五、保持不变的规则
- 每日计划中的 XP、经验、修为仍会被忽略，奖励由统一时长档位计算；
- 修炼任务与每日任务仍然分开保存、可以关联但不会互相冒充；
- 39 阶境界和逐阶不同的经验需求保持不变；
- 雷劫仍只在金丹以上、达到下一大境界门槛前开启；
- 联机扩展仍默认关闭，不排队、不上传、不拉取；
- 科研原文件仍只保存在本人节点。

六、数据边界
- 个性化包不包含论文、数据、交付附件、API 密钥或联机 Token。
- “一键导出知识库”包含 Markdown、JSON、原附件和结构化索引。
- “完整备份”用于恢复整套个人数据库和科研文件。
- 不要通过文件管理器手动删除 instance 或 storage。

七、安全更新
以后从联机中心下载新版 ZIP 后，可以在旧版目录双击：
安全安装新版本.cmd

它会先生成恢复备份，再将新版安装到同级新目录并迁移个人数据，不覆盖旧目录。确认新版可用前请保留旧目录。
