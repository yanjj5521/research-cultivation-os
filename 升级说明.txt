问道科研 v1.2 → v1.3

一、个人节点升级
1. 在旧版中点击“备份全部数据”。
2. 下载并完整解压 v1.3。
3. 关闭旧版网页和黑色命令窗口。
4. 双击 v1.3 的 Restore_Data.cmd，选择旧版备份 ZIP。
5. 双击 启动科研系统.cmd。
6. 旧论文、笔记、交付、数据集、实验、LAMMPS、计划、灵石、洞府和个性化数据会保留。

二、v1.3 变化
- 首页改为山门，只保留开始修炼、温故知新、入定闭关和知识库四个入口；
- 完整菜单仍在侧边抽屉和“更多工具”中，没有删除旧功能；
- 新增可自定义的山门古诗与轻量动态效果；
- 新增 25 / 45 / 90 分钟和自定义闭关倒计时；
- 新增 Markdown + JSON + 原附件的一键知识库导出；
- 头像可选择字印或上传图片，并随完整备份与 v3 个性化包迁移；
- 个性化导入继续兼容 v1、v2。

三、使用安全更新器
以后从联机中心下载新版ZIP后，可以在旧版目录双击：
安全安装新版本.cmd

它会：
- 先生成恢复备份；
- 将新版安装到同级新目录；
- 迁移个人数据；
- 不覆盖旧目录。

四、启用联机中心
1. 选择一台常开的电脑或VPS。
2. 双击 启动联机中心.cmd。
3. 打开 instance/HUB_ADMIN_CREDENTIALS.txt。
4. 用随机管理员密码登录并立即改密码。
5. 创建邀请码，成员分别注册。
6. 成员复制自己的API Token到个人节点“联机同步”页面。

五、重要边界
- 不要将旧版 personal SQLite 数据库直接放到共享盘供多人访问。
- 不要把管理员的 hub.db 复制给成员。
- 个人科研文件不会自动上传中心。
- 中心只同步个人主页、资产、法器建筑、个性化、资料卡和版本信息。
