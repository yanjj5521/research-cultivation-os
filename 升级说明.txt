科研系统 1.0（技术版本 v3.0.0）升级说明
========================================

一、个人端升级

1. 下载 ResearchOS-v3.0.0-Windows-x64.exe。
2. 关闭正在运行的旧版，再启动新 EXE。
3. 旧数据仍从 %LOCALAPPDATA%\ResearchCultivationOS 自动读取，无需复制。
4. 首次启动后，旧默认名称“问道科研”会改为“科研系统”；用户自己改过的名称不会被覆盖。

二、联机端升级

1. 中心主机更新为 ResearchHub-v3.0.0-Windows-x64.exe。
2. Android 用户更新为 ResearchOS-Mobile-v3.0.0-Android.apk。
3. 原账号、Token、轻量资产和个性化状态保留。
4. 个人论文、实验原始数据、附件和本地 SQLite 数据库仍不会上传到中心。

三、本版新增迁移

- 新增课题—工作区多对多关联表；
- 每日任务可关联工作区和课题；
- 新增动效、几何、字号和主页效果等本地设置；
- 个性化包升级为 v8，并兼容 v1–v7；
- 导航新增成就图鉴；
- 扩展法器、秘境和彩蛋数据。

四、版本保留

- 旧公开和私有 release 分支保持不变；
- 本版使用 release/v3.0.0 和 GitHub Release 标签 v3.0.0；
- 产品显示名称为“科研系统 1.0”，技术版本升至 3.0.0 是为了保证旧版升级判断正确。

升级前建议先在“系统设置与备份”下载一次完整 ZIP。
