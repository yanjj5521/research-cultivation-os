问道科研 v2.0.2 → v2.1.0

一、普通 Windows 用户
1. 打开 GitHub Releases，下载 ResearchCultivationOS-v2.1.0-Windows-x64.zip。
2. 完整解压到一个新目录，不要只把 ResearchOS.exe 拖出来。
3. 双击 ResearchOS.exe；不需要预装 Python，也不需要管理员权限。
4. 首次启动会在当前账户的 %LOCALAPPDATA%\ResearchCultivationOS 建立个人数据目录。
5. 从旧源码版迁移时，双击“迁移旧版数据.cmd”，选择旧版根目录。

程序目录可整体替换，个人数据库、附件和个性化仍保存在独立数据目录。升级前仍建议在“设置与备份”中生成一次完整备份。

二、CMD 与 EXE 的分工
- ResearchOS.exe 是普通使用和公开发布入口，依赖已随发行目录打包。
- “启动问道科研.cmd”只是方便查看启动日志的入口，仍调用同一个 EXE。
- 源码仓库里的 run_local.py / 原 CMD 用于开发和调试，需要 Python 与依赖。
- 不把数据库、论文、数据集、实验、附件、Token 或个人配置焊进 EXE。

三、首页
- 保留 v2.0.2 的山门、每日诗句、头像、境界、双检索和四个核心入口；
- 保留轻量工作台，不恢复任务仪表盘、论文轮播、每日一问、闪念或奖励卡；
- 最多显示本人固定的 6 个工作区；
- 底部只补最近保存、可用工作区数量、数据位置和版本/备份入口；
- 低高度桌面继续压缩显示，窄屏允许自然滚动。

四、六个默认工作区
- EG 实验：样品、配方、过程、原始曲线、异常、重复性和结论边界；
- LAMMPS：input/data、势函数、程序版本、命令、log/dump/restart 和通过标准；
- 数据集：来源许可、字段单位、清洗版本、缺失异常、适用边界和拆分；
- ML：数据与代码版本、特征、参数、指标、产物、误差分析和外部验证；
- MD：结构、力场、电荷、平衡、生产、轨迹和分析脚本；
- COMSOL：方程假设、几何材料、边界、网格无关性、求解器和实验校核。

每个工作区都能改名、换图标、换色、排序、启停、固定到首页、修改当前目标、编辑 4–6 步流程和选择常用组件。点击“恢复推荐搭配”只恢复流程与组件，不会删除资料或改回名称。

五、旧数据升级
首次启动会把数据库版本更新为 2.1.0，并只补齐缺少的字段和默认工作区。旧论文、笔记、闪念、交付、数据集、实验、模拟、计划、修为、灵石、洞府、头像、39 阶境界、雷劫记录、自定义导航、工作区改名/顺序/启停和联机关闭状态不会删除或重置。

六、U 盘便携模式
双击“便携模式启动.cmd”后，个人数据写到发行目录旁的 user_data。移动时必须携带整个解压目录；不要在公共电脑留下未加密的个人资料。

七、公开发布与开发版
- GitHub main 只放通过回归的稳定源码；
- GitHub Releases 提供普通用户下载的 Windows ZIP 与 SHA-256；
- 未完成开发保存在另一个本地目录或私有仓库，不推送到公开分支；
- 同一公开仓库里的分支同样公开，不能用公开开发分支隐藏源码。
