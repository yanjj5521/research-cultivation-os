问道科研 v2.3.0 → v2.3.1

一、普通 Windows 用户
1. 下载 ResearchOS-v2.3.1-Windows-x64.exe。
2. 双击即可使用，不需要解压、Python、pip 或管理员权限。
3. 旧数据仍从 %LOCALAPPDATA%\ResearchCultivationOS 读取，无需复制。
4. 升级前建议先在“设置与备份”中生成一次完整备份。

二、联机中心与 Android
1. 中心主机更新为 ResearchHub-v2.3.1-Windows-x64.exe。
2. Android 用户更新为 ResearchOS-Mobile-v2.3.1-Android.apk。
3. 中心地址、Token、成员、法器和轻量同步状态均保留。
4. 论文、实验数据库、笔记和附件仍只保存在个人电脑。

三、自定义导航
1. 打开“设置与备份”，找到“导航顺序与显示”。
2. 拖动分组或条目调整顺序；手机和窄屏可使用上下箭头。
3. 每个固定入口都可显示或隐藏。
4. 启用中的动态工作区入口可作为整体显示或隐藏。
5. 点击“恢复默认”可恢复默认顺序与显示状态。
6. 即使隐藏“设置与备份”，侧栏底部仍有“调整导航”入口。

四、个性化 v7
- 导航名称、分组顺序、条目顺序和显示状态进入个性化包；
- 继续兼容 v1–v6 个性化包；
- ResearchHub 只同步经过校验的轻量布局，不同步科研原文件。

五、旧数据升级
首次启动会新增并标准化 nav_layout 设置，把数据库版本更新为 2.3.1。
现有计划、课题、生涯节点、论文、笔记、交付、数据集、实验、模拟、
修为、灵石、法器、洞府、头像、境界、导航名称、工作区与联机配置
不会删除或重置。

六、版本保存
- 公开和私有 release/v2.3.0 均保持不变；
- 本版新增公开和私有 release/v2.3.1；
- GitHub Release 标签为 v2.3.1，并提供两个 EXE、Android APK、
  完整 ZIP 与统一 SHA-256。
